✨ Core Features

Visual Drag & Drop Editor

Place Signature, Initial, Text, Multiline Text, Checkbox, and Radio fields anywhere on multi-page PDF documents.

Sequential Multi-Signer Flow

Enforce role-based turn sequence (Signer 1 → Signer 2) with automated email dispatch and sequence protection.

Public Template Share Links

Generate public sharing URLs with validity expiration dates for open template signature collection.

Direct Email & Chatter Tracking

Sends custom HTML emails directly via mail.mail and logs all signature actions directly into Odoo Chatter.

OTP One-Time Password Security

Optional Extra Security mode requiring signers to verify a 6-digit email OTP before accessing sensitive files.

Signer Delegation & Refusal Flow

Allows signers to transfer signing responsibility to another partner or refuse with logged justification reasons.

1-Click Saved Profile Signatures

Store signatures on Partner records for 1-click electronic signing and auto-fill contact information.

Completed PDF Document Generation

Merges all completed signatures and filled form text directly into the final PDF attachment upon completion.

Auto Reminders & CC Notifications

Automatically resends pending signature reminder emails every 3 days via scheduled CRON, and distributes the completed signed document to all configured CC recipients.

🔄 Operational Workflows

Comprehensive end-to-end document signing lifecycle management

1. Visual PDF Template Builder

Upload any PDF agreement or contract. Drag and drop signature blocks, initials, contact text boxes, and checkboxes onto the exact coordinates of the page. Assign each field to specific signer roles (Signer 1, Signer 2, etc.).

  • Drag & Drop Field Placement
  • Role-based Field Assignment
  • Multi-page PDF Template Support

PDF Template Editor

Interactive canvas editor with real-time field positioning.

2. Sequential Signature Requests

Send signature requests to single or multiple recipients. The system automatically sends an email notification to the active signer with a secure access token link, while keeping subsequent signers in a "Waiting" state until their turn.

  • Automated Recipient Email Routing
  • Secure Per-Signer Access Tokens
  • "Not Yet Your Turn" Sequence Guard

Sequential Multi-Signer Flow

Automated turn-based email notifications & sequence protection.

3. Activity Logging & PDF Generation

Once all signers complete their signatures, Easy Sign embeds all signatures and filled text values directly onto the PDF document and attaches it to the record. Complete audit logs tracking IP addresses and timestamps are recorded in Odoo.

  • Direct PDF Signature Embedding
  • Complete Sign Log & IP Address Audit
  • Automatic Completion Email Attachments

Activity Log & Final PDF

Complete signer activity log with IP tracking & attached final document.

⚙️ Installation

📁 Step 1: Copy Module

Copy the easy_sign folder into your Odoo custom addons path.

/opt/odoo/custom/addons/easy_sign
⚙️ Step 2: Install App

Activate Developer Mode → Go to Apps → Update Apps List → Search for Easy Sign and Install.

🚀 Step 3: Restart Odoo

Restart your Odoo service for changes to take effect.

sudo systemctl restart odoo
✅ Step 4: Start Signing

After installation, go to Easy Sign → Templates to upload your first PDF document and start creating signature requests.
